# Contributing to Nylon Pay (public hub)

Thanks for helping. This repo is the **overview hub** — not where SDK source lives.

## Request a language SDK

1. [Open an issue](https://github.com/nile-squad/nylonpay-overview/issues/new?labels=sdk-request) titled `SDK request: <Language>`.
2. Or message the [WhatsApp community](https://chat.whatsapp.com/DNVS6PjCL0vLgx8rQJFFaF).

Include: language, runtime version, and whether you can help implement against the [SDK spec](https://github.com/nile-squad/specs/blob/main/nylonpay-sdk-spec/spec.md).

## Report a docs problem

1. Note the page URL (e.g. `https://docs.nylonpay.nilesquad.com/docs/sdk/collect-payment`).
2. [Open a docs issue](https://github.com/nile-squad/nylonpay-overview/issues/new?labels=docs) with what’s wrong or missing.
3. Or ask on [WhatsApp](https://chat.whatsapp.com/DNVS6PjCL0vLgx8rQJFFaF).

## Contribute code to an SDK

Work in the language repo:

| Language | Repository |
|----------|------------|
| TypeScript | https://github.com/nile-squad/nylonpay-ts |
| Python | https://github.com/nile-squad/nylonpay-py |
| PHP | https://github.com/nile-squad/nylonpay-php |

Follow that repo’s README and the shared [SDK specification](https://github.com/nile-squad/specs/blob/main/nylonpay-sdk-spec/spec.md).
