# Contributing to Nylon Pay (public hub)

Thanks for helping. This repo is the **overview hub**, not where SDK source lives.

## Request a language SDK

1. [Open an issue](https://github.com/nile-squad/nylonpay-overview/issues/new?labels=sdk-request&template=sdk-request.md) titled `SDK request: <Language>`.
2. Or message the [WhatsApp community](https://chat.whatsapp.com/DNVS6PjCL0vLgx8rQJFFaF).

Include: language, runtime version, and whether you can help implement against the [SDK spec](https://github.com/nile-squad/specs/blob/main/nylonpay-sdk-spec/spec.md).

## Report a docs problem

1. Note the page URL (for example `https://docs.nylonpay.nilesquad.com/docs/sdk/collect-payment`).
2. [Open a docs issue](https://github.com/nile-squad/nylonpay-overview/issues/new?labels=docs&template=docs-fix.md) with what is wrong or missing.
3. Or ask on [WhatsApp](https://chat.whatsapp.com/DNVS6PjCL0vLgx8rQJFFaF).
